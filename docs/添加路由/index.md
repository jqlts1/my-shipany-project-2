## 常见问题

**Q: 页面 URL 是如何决定的？**
A: `src/config/locale/messages/en/pages/xxx.json` 对应的 URL 就是 `/xxx`。如果你创建的是文件夹结构 `pages/help/center.json`，URL 就是 `/help/center`。

**Q: 如何修改页面的 SEO 标题？**
A: 在 JSON 文件的 `metadata` 字段中修改 `title` 和 `description`。
