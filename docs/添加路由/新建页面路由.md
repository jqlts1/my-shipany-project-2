# 新建页面路由

本文档介绍如何在项目中新增一个配置化页面。

## 核心流程

现在的路由系统支持**自动化路由**，新增页面只需要 **1 步**：

1. **创建配置文件** (JSON)

系统会根据文件名自动生成路由，**无需手动注册**。

---

## Step 1: 创建配置文件

在 `src/config/locale/messages/en/pages/` 目录下新建一个 JSON 文件。
文件名即为你的路由名称（URL 路径一部分）。

**示例：** `src/config/locale/messages/en/pages/about.json`

```json
{
    "metadata": {
        "title": "About Us",
        "description": "Learn more about our company",
        // 可选：定时发布。只有当时间超过此设置后，页面才会对用户可见。
        "publishedAt": "2025-12-31T12:00:00Z" 
    },
    "page": {
        "sections": {
            "hero": {
                "block": "hero",
                "title": "About Us",
                "description": "We are a great team."
            },
            "team": {
                "block": "features-grid",
                "title": "Our Team",
                "items": []
            }
        }
    }
}
```

> **提示**：如果是多语言项目，记得在 `src/config/locale/messages/zh/pages/` 下也创建同名文件。

### 配置说明

*   **metadata**: 页面 SEO 信息（标题、描述）。
    *   **publishedAt (可选)**: 定时发布时间 (ISO 8601 格式)。
        *   如果不填：页面立即发布。
        *   如果填了未来时间：页面返回 404，直到时间到达。
*   **page.sections**: 区块列表。key 为区块唯一标识 ID，value 为配置对象。
*   **block 字段**: 指定使用哪个组件（例如 `hero`, `features` 等）。如果不写，默认使用 key 作为 block 名。

> 🔍 **查看所有可用区块**：请查阅 **[系统默认区块](./系统默认区块.md)** 文档。

---

## 访问页面

保存 JSON 文件后，无需重启，直接访问对应的 URL 即可：

*   `src/config/locale/messages/en/pages/about.json` -> `http://localhost:3000/about`
*   `src/config/locale/messages/en/pages/services/consulting.json` -> `http://localhost:3000/services/consulting`
