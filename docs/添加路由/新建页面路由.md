# 新建页面路由

本文档介绍如何在项目中新增一个配置化页面。

## 核心流程

新增页面只需要两步：

1. **创建配置文件** (JSON)
2. **注册路由** (`index.ts`)

---

## Step 1: 创建配置文件

在 `src/config/locale/messages/en/pages/` 目录下新建一个 JSON 文件。
文件名即为你的路由名称（URL 路径一部分）。

**示例：** `src/config/locale/messages/en/pages/about.json`

```json
{
    "metadata": {
        "title": "About Us",
        "description": "Learn more about our company"
    },
    "page": {
        "sections": {
            "hero": {
                "block": "hero",
                "title": "About Us",
                "description": "We are a great team."
            },
            "team": {
                "block": "features-grid",
                "title": "Our Team",
                "items": []
            }
        }
    }
}
```

> **提示**：如果是多语言项目，记得在 `src/config/locale/messages/zh/pages/` 下也创建同名文件。

### 配置说明

*   **metadata**: 页面 SEO 信息（标题、描述）。
*   **page.sections**: 区块列表。key 为区块唯一标识 ID，value 为配置对象。
*   **block 字段**: 指定使用哪个组件（例如 `hero`, `features` 等）。如果不写，默认使用 key 作为 block 名。

> 🔍 **查看所有可用区块**：请查阅 **[系统默认区块](./系统默认区块.md)** 文档。

---

## Step 2: 注册路由

打开 `src/config/locale/index.ts`，在 `localeMessagesPaths` 数组中添加新页面的路径。

**注意**：路径不需要包含 `locale` 目录和 `.json` 后缀。

```typescript
// src/config/locale/index.ts

export const localeMessagesPaths = [
  // ... 其他页面
  'pages/home',
  'pages/generate',
  
  // 新增的页面
  'pages/about' 
];
```

保存后，你就可以访问 `http://localhost:3000/about` 查看效果了。
