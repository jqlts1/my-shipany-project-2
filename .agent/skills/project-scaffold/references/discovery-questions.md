# Discovery Questions (项目信息收集问题)

## 必填问题

在创建新项目时，收集以下核心信息：

### 1. 基础信息

```markdown
1. **项目名称**：你的品牌/产品叫什么名字？
   - 用于：GitHub 仓库名、网站标题、Logo 文字

2. **一句话描述**：用一句话描述这个产品是做什么的？
   - 用于：Hero 区块的 subtitle、SEO description

3. **目标用户**：主要服务哪类人群？
   - 示例：设计师、开发者、企业主、学生
   - 用于：确定文案风格和功能优先级
```

### 2. 功能信息

```markdown
4. **核心功能**：列出 3-5 个主要功能
   - 示例：AI 去背景、批量处理、云端存储
   - 用于：Features 区块

5. **核心价值/卖点**：为什么用户要选择你的产品？
   - 示例：比竞品快 10 倍、免费使用、隐私保护
   - 用于：Benefits 区块
```

### 3. 竞品参考（可选）

```markdown
6. **竞品参考**：有没有类似的产品可以参考？
   - 示例：类似 Canva 但更简单
   - 用于：理解产品定位
```

---

## 可选问题

根据用户需求，可以追问：

```markdown
7. **主色调偏好**：有没有偏好的颜色？
   - 默认：由 AI 根据行业建议

8. **需要哪些页面**：
   - 默认：首页、功能介绍、定价、FAQ
   - 可选：博客、关于我们、联系我们

9. **定价模式**：
   - 免费 / 免费试用 / 订阅制 / 一次性付费

10. **是否需要登录功能**：
    - 是 / 否（影响是否显示登录按钮）
```

## 输出格式

收集完成后，整理为以下格式供 `shipany-page-builder` 使用：

```json
{
  "projectName": "PicSet AI",
  "tagline": "AI 驱动的图片处理工具",
  "targetAudience": "设计师和内容创作者",
  "features": [
    "AI 去背景",
    "图片增强",
    "批量处理"
  ],
  "benefits": [
    "处理速度提升 10 倍",
    "无需下载软件",
    "隐私数据本地处理"
  ],
  "pages": ["home", "features", "pricing", "faq"],
  "primaryColor": "#6366f1"
}
```
